# XMinusYC — сайт минусовок (v2)

Self-hosted сайт минусовых фонограмм: слушать, менять тональность и темп, скачивать, петь с синхронным текстом.
**Node.js 22+**, Express, SQLite, чистый JS на фронтенде (без сборки).

## Быстрый старт

```bash
npm install
cp .env.example .env        # заполните минимум BASE_URL
npm start                   # http://localhost:3000
```

При первом запуске создаётся администратор. **Пароль показывается в консоли один раз** (или берётся из `ADMIN_PASSWORD`).

> Установка: именно `npm install` (без `npm ci`). Готовые бинарники SQLite для Windows/macOS/Linux идут внутри пакета, компилятор не нужен.

## Переход со старой версии (db.json)

1. Скопируйте из старого проекта в новый: `data/` и `public/uploads`, `public/covers`, `public/avatars`, `public/artists`.
2. `npm install && npm start`.

Автоматически произойдёт: перенос `db.json` и `reports.json` в SQLite (старые файлы получат суффикс `.migrated`),
перенос аудио из `public/uploads` в закрытое `storage/audio`, замена небезопасного пароля `admin123`.
**Сделайте копию старой папки до первого запуска.** Секреты из старого `.env`/`smtp.json` перевыпустите и положите в новый `.env`.

## Что есть

**Для слушателей:** поиск без учёта регистра/ё и по транслиту (`zemfira` найдёт «Земфира»), фильтры по тональности, жанру, языку и типу,
смена тональности (±12) и темпа (50–150%) независимо, скачивание с применёнными эффектами в MP3, **караоке с синхронным текстом (LRC)**,
подсказка итоговой тональности («Am → Bm»), автопереход к следующему треку, история прослушиваний, управление с экрана блокировки (Media Session),
установка как приложение (PWA), 16 языков (новые строки — ru/en, остальные языки откатываются на русский).

**Для авторов:** загрузка аудио с проверкой реального формата, длительность и битрейт определяются автоматически, обложки, LRC-текст, коллекции, профиль.

**Для администратора:** панель `/admin` (статистика за 30 дней, пользователи с блокировкой, очередь жалоб), модерация треков, заявки аранжировщиков.

**Правовые страницы:** `/terms`, форма заявления правообладателя `/copyright` (попадает в очередь админа и на `REPORT_EMAIL`).
Текст правил — шаблон, адаптируйте под себя и вашу юрисдикцию.

## Безопасность (что сделано)

- Секреты только из `.env`; пароль админа не хардкодится; секрет сессий генерируется автоматически; сессии хранятся в SQLite.
- `helmet` + строгая CSP (скрипты только свои, без CDN), защита от CSRF по Origin, rate-limit на вход/регистрацию/письма/жалобы/загрузки.
- Загрузки проверяются по сигнатуре файла (не по расширению), аудио хранится вне `public/` и отдаётся только для видимых треков.
- OAuth с параметром `state`; привязка к существующему аккаунту по email только при подтверждённом провайдером адресе.
- Блокировка пользователей мгновенно завершает сессии; роли берутся из БД на каждый запрос.
- Счётчик прослушиваний считает реальное воспроизведение, не чаще раза в 30 минут с одного адреса/аккаунта.

## Данные и резервные копии

- БД: `data/xminyc.sqlite`. Ежедневная копия: `data/backups/` (хранится `BACKUP_KEEP` штук), вручную: `npm run backup`.
- **Аудио и картинки в бэкап БД не входят** — копируйте `storage/audio` и `public/{covers,avatars,artists}` (rsync/restic/облако).

## Деплой за прокси

Укажите `BASE_URL=https://ваш.домен`, `TRUST_PROXY=1`. Куки автоматически станут `Secure` для https.
Для nginx добавьте `client_max_body_size 60m;`.

## SEO

Адреса без `#` (`/track/12`), сервер подставляет title/description/Open Graph для треков и исполнителей, есть `/sitemap.xml` и `/robots.txt`.
Старые ссылки вида `/#/track/12` автоматически перенаправляются.

## Структура

```
server.js            точка входа
src/config.js        конфигурация из .env
src/db/store.js      SQLite-хранилище (API прежний)
src/db/migrate.js    миграция из db.json
src/routes/*         API: auth, tracks, users, artists, collections, arrangers, reports, admin, media
src/middleware/*     auth, безопасность, rate-limit
src/seo.js           мета-теги, sitemap
public/js/app.js     основное приложение;  features.js — караоке, админка, фильтры, PWA и др.
```
